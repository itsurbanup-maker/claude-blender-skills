# Wildcards

- When a skill generates N options from a reference database, make about 20 % of them wildcards (e.g. 2 of 10).
- A wildcard ignores the references completely: new angle, new style, new structure. It must still fit the brief.
- Label wildcards clearly so the user can judge them separately.
- If the user likes a wildcard, offer to add it to the reference database as a new reference.
