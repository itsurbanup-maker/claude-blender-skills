# Instructions for this repo

This repo is a set of Claude skills (`skills/<name>/SKILL.md` + scripts) for making films: built and rendered in Blender,
edited in Adobe Premiere Pro, finished in Adobe After Effects.

This project is yours. You decide how it is built, and you will keep building on it.

Don't stop while work I asked for is still left. If you hit a normal error, find out what happened and keep going.
If something is blocked on purpose, leave it blocked and tell me.

Every few actions, tell me in one line where you are.

Write the final report for a smart person who did not see your work. Main points first. Simple words, short sentences,
one idea per sentence, no abbreviations you made up.

When you write or edit a skill, follow `skills/claude-agent-rules/SKILL.md`: no stale notes, no "never" without its exception
in the same sentence, no rigid style limits, no "always use sub-agents".

Scripts for Premiere and After Effects can't run in a cloud session without those apps. Test their logic with ffmpeg and
fake inputs, and say clearly what was not tested in the real app.
